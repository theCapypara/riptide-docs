## Raw Changelog

- Hooks ([LINK](/user_docs/hooks))
- `riptide log` ([LINK](/user_docs/log_files))
- Redesigned CLI & Proxy; New Riptide logo
- sort services & commands in various CLI outputs and the proxy server landing page
- Set minimum Python version to 3.11
- Fix handling of invalid env files
- This release changes parent() so that it returns None if no parent is defined, instead of returning the document parent() was called on. This was already the documented behavior before, this change fixes the implementation. Nonetheless this is a breaking change.
- Configcrunch now supports null values in documents
- cc: Fixed path handling under Windows
- ripsu: no more su problems, su no longer required in images [aarch64]
- TTY improvements, piping now supported, CTRL+D required for PHP
- setproctitle
- Allow specifying path to riptide config directory: `RIPTIDE_CONFIG_DIR`
- Support platform-specific additional volumes (Command/Service.additional_volumes.<key>.host_system)
- Add special handling for SSH agents on macOS (thanks to @jeliebig) - /run/host-services/ssh-auth.sock
- Better pre_start error messages
- Additional validation for additional volumes handling, see (Command/Service.additional_volumes.<key>.type)
- Prevent volume_name from being used for file paths
- Better error message for binary files used with 'config'
- Logs
- `riptide_upgrade` will now prompt you to restart the Proxy server
- Fix infinite exception loop when starting containers in the foreground
- Riptide now supports the `DOCKER_DEFAULT_PLATFORM` environment variable. It will be used to tell Docker which image architecture to pull images for, instead of the system's architecture.
